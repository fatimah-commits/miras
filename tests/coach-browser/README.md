# اختبارات المدرب المباشر في المتصفح

تشغّل صفحة `coach/` في Chromium آلياً على صورة لوحة تجارب **حقيقية** (من مجموعة صور عامة، غير مرفقة هنا)،
مع حركة كاميرا وإضاءة ويد **مصنوعة** فوقها، وأسلاك مرسومة في فتحات معروفة. ليست بديلاً عن تجربة الكاميرا الحقيقية على الآيباد.

- `gen_motion.py` + `tracking.js`: يقيس انحراف الإرشادات عن مكانها الصحيح (بالبكسل) مع الحركة والإضاءة واليد والقفزة.
- `gen_wires.py` + `wires.js`: 9 حالات أسلاك (صحيح، قطبية معكوسة، قصر، إضاءة خافتة وقوية).
- `session.js`: جلسة كاملة بالأزرار في وضعي التدريب والاختبار، ثم التقرير.
- `early-warning.js`: تحذير مبكر أثناء وجود اليد، ثم خطأ مؤكد بعد ثبات الصورة.

الاختبارات المنطقية بدون متصفح: `node tests/coach-logic.test.js`
