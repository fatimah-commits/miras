# مراس · Miras

منصة تدريب عملي على مهارات لوحة التجارب والأردوينو، بالكاميرا والرؤية الحاسوبية.

الموقع: https://fatimah-commits.github.io/miras/

نموذج أولي للعرض في STIEX 2026. بيانات الدخول والمتدربات تجريبية.

الدخول التجريبي: متدربة 4410201 أو مدربة 9001، وكلمة المرور 1234.

## المدرب المباشر (تجريبي)

`coach/`: إرشاد فوق اللوحة الحقيقية في الكاميرا، وفحص إلزامي قبل توصيل كيبل USB، ووضعا تدريب واختبار، وتقرير حماية الأدوات من جلسات حقيقية فقط.
يستخدم نموذج `lab/miras-parts.onnx` نفسه. الموقع لا يفصل الكهرباء آلياً: الحماية إجرائية (الكيبل يبقى مفصولاً حتى يجتاز الفحص).

النسخة الأصلية قبل هذه الإضافة محفوظة في الفرع `original-2026-11-14-branch`.
